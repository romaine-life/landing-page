# landing-page

Static landing page for [romaine.life](https://romaine.life).

Served from AKS (namespace `landing-page`) via a minimal Node+Express container behind the shared Envoy Gateway. CI comes from pipeline-templates' suites (its `fleet.json` entry): the image is built with fzt-browser's files and the String Box model, the npm packages `@romaine-life/fzt-browser` (in `backend/package.json`, served at `/fzh/`) and `@romaine-life/string-box` (in `string-box/package.json`) from Forgejo's registry, run with `--self-test`, pushed to `romainecr.azurecr.io/landing-page`, and pinned in `k8s/values.yaml` by a PR merge-queue lands; Argo CD renders the Helm chart in `k8s/`. A new fzt-browser or String Box release proposes its package as a take-up PR. `npm install` in `backend/` or `string-box/` reads them with the token in `FORGEJO_PACKAGES_TOKEN` (`ci-check` signs in for you; pipeline-templates `suites/README.md`, npm packages on Forgejo).

`string-box/` is the String Box page at [romaine.life/string-box](https://romaine.life/string-box/): the board in 3D (three.js), then how it works (a 2D canvas, `src/scope.js`), built by Vite in the Dockerfile. Its model, `renders/string-box.glb`, is made in romaine-life/string-box by `hardware/web3d.sh` and comes from that repository's npm package; `npm run build` copies it into `public/`, so for local work run `npm run prebuild` once, then `npm run dev`, in `string-box/`.
