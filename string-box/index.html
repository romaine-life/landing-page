String Box

A six-channel receiver for a hexaphonic guitar pickup. Every string gets its own preamp and converter, and a Teensy 4.1 streams all six to a PC over USB, so visuals can follow the real motion of each string.

    How it works ↓

    A normal pickup hears a chord. String Box hears six strings.

    An electric guitar's pickup sums all six strings into one signal, so by the time it reaches a computer, which string rang, and how hard, is mixed away. String Box keeps them apart.

    1. The pickup

      A hexaphonic pickup (here a SubSix) has a separate coil under each string, so it puts out six signals instead of one, on two small cables.

    2. The board

      Each signal gets its own preamp, with a trimmer to set that string's gain, and its own converter, which measures it about 44,000 times a second.

    3. The computer

      A Teensy 4.1 streams all six to a PC over USB, where visuals can react to each string on its own: which one rang, how hard, and for how long. The guitar's sound still goes through a microphone; String Box carries only the strings' motion.

    Drag the board to turn it. The back's silkscreen is six string recordings from GuitarSet (CC BY 4.0).
